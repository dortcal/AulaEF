# AULAOLIMPIADAS: El Gran Desafío

Videojuego educativo de Educación Física para días de lluvia (Educación Primaria). Un único archivo `index.html` que funciona sin conexión: se abre en el navegador y se proyecta en la pizarra digital.

## Cómo usarlo
Abre `index.html` en Chrome, Firefox o Edge. Si activas GitHub Pages (Settings → Pages → rama `main`, carpeta raíz), también estará disponible como página web.
